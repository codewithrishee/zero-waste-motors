# Zero Waste Motors — PHP Starter

Premium eco-luxury vehicle recycling website starter structure.

## Stack
- PHP 8+
- MySQL (PDO)
- Bootstrap 5 (to be added)
- Vanilla JavaScript

## Setup
1. Place this folder in your local PHP server directory (for example, `htdocs`).
2. Configure database settings in `config/database.php` when database work begins.
3. Open `index.php` through your local server.

Folder structure is prepared for frontend pages, reusable components, form handlers, assets, and the `ManageAdmin` area.
